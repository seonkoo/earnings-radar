# 财报舆情雷达 · GitHub 自动版

每天自动抓取 A 股**财报公告**（东方财富公开接口），判**利好 / 利空 / 中性**，聚合成**个股参考权重指数**，归档成每日快照。手机浏览器打开即可看，无需服务器、无需你电脑在线。

> 与 [market-radar](https://github.com/seonkoo/market-radar) 互补：market-radar 看**板块资金流**，本站看**个股财报舆情**。

## 它每天生成什么

- **概览**：当日利好 / 利空 / 中性 公告数
- **个股参考权重榜**：每只被财报公告提及的个股，按 `净情绪 = 利好数 − 利空数` 排序，给出 0–100 的参考权重（50 为中性）
- **财报公告流**：原始公告 + 利好/利空标签 + 涉及个股
- **历史快照**：每次抓取归档一帧，可回看近 14 日舆情变化

## 自动机制（重点：不依赖你电脑）

- `.github/workflows/daily.yml`：cron `30 0` / `0 14` UTC = **北京时间 08:30 / 22:00** + 手动触发
- `generate.py`：服务端抓取东方财富 `np-anotice-stock.eastmoney.com` 公告接口（仅标准库），筛选财报相关 → 关键词判利好/利空 → 聚合个股权重 → 写 `latest.json` + 归档 `snapshots/`
- 首次运行通过 `gh api` 自动启用 GitHub Pages（无需手动开）
- 你关机/出门，GitHub 服务器照常每天跑

## 怎么用

1. 手机/电脑浏览器打开 `https://seonkoo.github.io/earnings-radar/`
2. 打开即拉**服务器快照**（每日 08:30 / 22:00 生成的那份）
3. 点 **🔄 实时刷新**：手机浏览器直连东方财富拉最新（实时接口若被跨域限制，自动回退快照）
4. 想立刻看最新：去仓库 `Actions` → `每日财报舆情抓取` → `Run workflow` 手动触发

## 诚实边界

- 利好/利空是**标题关键词启发式判定**（预增/扭亏=利好，预减/首亏/ST=利空等），存在误差，**不是预测**，不预知股价涨跌。
- 数据源为**官方财报公告**（业绩预告/快报/报告/利润分配/说明会等），自带股票代码，最权威；不含媒体二传情绪。
- 海外 GitHub 机器抓取东方财富偶发受地域/限流影响：某次为空时，页面会自动改用手机实时抓取。
- 仅供个人学习参考，**不构成任何投资建议**。

## 文件

- `index.html` —— 手机版单文件页面（快照 + 实时兜底 + 历史）
- `generate.py` —— 服务端抓取脚本（仅标准库）
- `latest.json` —— 最近一次服务器快照
- `snapshots/` —— 历史快照归档（`index.json` 为运行记录）
- `.github/workflows/daily.yml` —— 定时任务
