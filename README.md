# 财报舆情雷达 · 多维度自动版

每天自动抓取 A 股**板块资金流 + 财报舆情 + 财经要闻**，聚合成一个手机可看的**多维度仪表盘**，无需服务器、无需你电脑在线。

> 与 [market-radar](https://github.com/seonkoo/market-radar) 互补：market-radar 是板块资金流单站，本站是**财报舆情 + 板块资金流 + 情绪罗盘 + 要闻**的多 Tab 综合体（板块/资金/轮动/情绪罗盘/要闻模块直接复用 market-radar 已验证的代码）。

## 它每天生成什么（6 个 Tab）

| Tab | 内容 |
|---|---|
| **概览** | 大盘概况 + 财报舆情速览 + 市场情绪罗盘 + 每日要闻 + 今日方向（早/晚报）+ 服务器快照记录 |
| **财报** | 个股参考权重榜（利好/利空→净情绪→0~100 权重）+ 财报公告流 + 近 14 日历史快照 |
| **板块** | 行业 / 概念板块主力净流入（涨跌·净流入·3日·连入·位置·概率·窗口） |
| **资金** | 轮动信号（谁在吸筹/抽血）+ 个股净流入 TOP12 + 行业净流出 TOP8 |
| **新闻** | 每日要闻（词库筛选+分组）+ 市场情绪罗盘（进攻/平缓/避险）+ 新闻信号扫描 |
| **我的** | 持仓纪律（止损/持有/止盈录入）+ 每日复盘打卡清单（本地保存） |

## 自动机制（重点：不依赖你电脑）

- `.github/workflows/daily.yml`：cron `30 0` / `0 14` UTC = **北京时间 08:30 / 22:00** + 手动触发（`concurrency` 防并发 push 冲突）
- `generate.py`（仅标准库）：双引擎 → ① 抓东方财富 `push2` 板块资金流（指数/行业/概念/个股/历史）② 抓 `np-anotice-stock` 财报公告 → 关键词判利好/利空 → 个股参考权重 → 合并写 `latest.json` + 归档 `snapshots/`
- `brief.py` + `lexicon.json`：抓新浪/东财财经新闻 → 词库匹配（进攻/平缓/避险）+ 否定词翻转 → 每日要闻 `brief.json`（可选 LLM 辅助：设 `ZHIPU_API_KEY` / `SILICONFLOW_API_KEY` 即启用）
- 首次运行通过 `gh api` 自动启用 GitHub Pages
- 你关机/出门，GitHub 服务器照常每天跑

## 怎么用

1. 手机/电脑浏览器打开 `https://seonkoo.github.io/earnings-radar/`
2. 打开即拉**服务器快照**（每日 08:30 / 22:00 生成的那份）
3. 点 **↻** 或各 Tab 的**实时刷新**：手机浏览器直连东方财富拉最新（实时失败自动回退快照）
4. 想立刻看最新：仓库 `Actions` → `每日财报舆情抓取` → `Run workflow` 手动触发

## 诚实边界

- 利好/利空、情绪罗盘、板块概率均为**标题/资金流关键词启发式判定**，存在误差，**不是预测**，不预知股价涨跌。
- 数据来源：东方财富公开接口（板块资金流 `push2`、财报公告 `np-anotice`、新浪/东财新闻），海外 GitHub 机器偶发受地域/限流影响，页面会自动改用手机实时抓取兜底。
- 仅供个人学习参考，**不构成任何投资建议**。

## 文件

- `index.html` —— 手机版多 Tab 页面（快照 + 实时兜底 + 历史）
- `generate.py` —— 服务端双引擎抓取脚本（仅标准库）
- `brief.py` / `build_lexicon.py` / `lexicon.json` —— 每日要闻与情绪罗盘引擎
- `latest.json` / `brief.json` —— 最近一次服务器快照
- `snapshots/` —— 历史快照归档（`index.json` 为运行记录，含每日财报舆情概览）
- `.github/workflows/daily.yml` —— 定时任务
